# Legacy reference archive

This directory contains the PHP implementation, static HTML prototypes, migration-era patch scripts, and original source images used while rebuilding Taghmesa.

It is retained for visual and data-migration reference only. It is not part of the production application and is excluded from Vercel deployments. The deployable application lives in the repository root and uses Next.js App Router.

- `php/`: previous PHP implementation and schema
- `prototypes/`: static storefront iterations
- `tools/`: one-off conversion and patch scripts
- `source-assets/`: original and duplicate source images
- `README-ar.md`: installation notes for the previous implementation
